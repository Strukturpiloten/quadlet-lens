# QuadletLens 0.1.10

- Adds native lifecycle and identity keys: `Entrypoint`, `RunInit`, `StopSignal`, `StopTimeout`,
  `Pull`, `PidsLimit`, `HostName`, and container/pod `ShmSize`.
- Adds resource and device keys: `DropCapability`, `AddCapability`, `Tmpfs`, `Sysctl`, `Ulimit`,
  `AddDevice`, and container `Memory`.
- Adds dry-run generator evidence for every recorded Podman patch from 5.4.0 through 6.0.2;
  `Memory` is native from 5.5.0.
- Preserves raw native values and remains additive within the 0.1.x API with Rust 1.85.0+ support.
