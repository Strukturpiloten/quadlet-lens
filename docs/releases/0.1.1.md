# QuadletLens 0.1.1

QuadletLens 0.1.1 is an additive patch release for programmatic native document generation. It is
the minimum version intended for BoxFerry's first Quadlet exporter.

## Added

- A typed `QuadletDocumentBuilder` for the supported `.container`, `.pod`, `.network`, and
  `.volume` native sections.
- Open-ended generation of `[Unit]`, `[Service]`, and `[Install]` directives.
- Exact one-line `EntryValue` validation without hidden quoting or normalization.
- Repeated-entry preservation, duplicate singleton rejection, deterministic section ordering, and
  parse-back validation.
- A consumer-level public API contract and generation-focused integration tests.

## Compatibility

This release is source-compatible with the documented QuadletLens 0.1.x API. It does not change
the Podman capability catalogue or extend its verified range beyond 5.4.0 through 6.0.2.

The builder validates document structure. Callers remain responsible for choosing correct native
value spellings for the intended Podman and systemd target; target-aware value encoders are not
part of this release.
