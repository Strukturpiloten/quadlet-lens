# QuadletLens 0.2.0

- Completes the current native Container, Pod, Network, Volume, Build, Image, Kube, Artifact, and
  Quadlet-section key model.
- Adds typed, reset-aware graph handling for nine reviewed systemd Unit relationships with real
  Podman 5.4.2, 5.5.0, and 6.0.2 generator evidence.
- Makes `quadlet_lens::model::SystemdUnitKey` the only public ownership path.
- Keeps parsing, rendering, capability evaluation, and document-set construction free of runtime
  mutation or implicit filesystem/process access.

## Migration from 0.1.x

Import `SystemdUnitKey` from `quadlet_lens::model` instead of `quadlet_lens::render`.
