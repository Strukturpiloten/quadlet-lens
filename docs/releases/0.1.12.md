# QuadletLens 0.1.12

- Adds native `.image` `Image`, `ImageTag`, `ServiceName`, `AllTags`, `Arch`, `AuthFile`, `CertDir`, `OS`, repeatable `ContainersConfModule`/`GlobalArgs`, and redacted-debug `Creds`/`DecryptionKey` support with exact Container/Volume document-set
  resolution; see the [typed model](../typed-model.md) and [coverage](../coverage.md).
- Completes the native Volume family with source-aware opaque construction and explicit capability
  evidence; see the [capability model](../capability-model.md).
- Completes the current native Build family with ordered opaque values and singleton construction;
  see [generation](../generation.md).
- Adds evidence-scoped generic `PodmanArgs`, configuration, logging, network identity, opaque
  reload-key support, and Pod `ExitPolicy`/`StopTimeout`/`ServiceName` without lifecycle or identity interpretation.
- Verifies the supported surface across the exact 20-release Podman matrix, including recorded
  version boundaries; see the [generator matrix](../generator-matrix.md).
- Compatibility remains finite and evidence-backed; parsing and rendering do not pull images, read
  registries, operate systemd, or run containers.
