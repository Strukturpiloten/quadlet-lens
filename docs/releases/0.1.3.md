# QuadletLens 0.1.3

QuadletLens 0.1.3 completes the native regular health-check timing subset needed by BoxFerry and
other generators while preserving the distinction between regular and startup health checks.

## Added

- `ContainerKey::HealthInterval` for the regular health-check interval.
- `ContainerKey::HealthRetries` for the unhealthy retry threshold.
- `ContainerKey::HealthStartPeriod` for the regular-check startup grace period.
- `ContainerKey::HealthTimeout` for the per-check timeout.
- Capability IDs for each key over Podman 5.4.0 through the finite current catalogue ceiling,
  Podman 6.0.2.
- Parser, builder, renderer, catalogue, and public-consumer tests for the additive key surface.
- Real-generator fixtures accepted by all 20 recorded Podman patch releases from 5.4.0 through
  6.0.2.

## Compatibility

The public changes are additive within the documented QuadletLens 0.1.x API. Existing callers do
not need to change. Rust 1.85.0 and Podman 5.4.0 remain the minimum supported versions; Podman 5.4
is not a maximum.

## Semantic boundary

The new keys model Podman's regular health-check settings. They do not claim that Compose
`start_interval` is equivalent to Podman's separate startup-healthcheck command, interval,
success, retry, and timeout mechanism. Readiness signaling with `Notify=healthy` and cross-service
ordering remain a later cohesive dependency slice.
