# QuadletLens 0.1.11

- Adds opaque native keys for DNS, exposed ports, annotations, AppArmor, no-new-privileges,
  seccomp, SELinux label settings, Mask, and Unmask (`ContainerKey` ordinals 41–55).
- Preserves physical values, order, duplicates, and reset assignments; singleton keys retain the
  standard duplicate diagnostic.
- Adds dry-run generator evidence across all 20 recorded Podman patches from 5.4.0 through 6.0.2.
  AppArmor is unsupported through 5.7.1 and native from 5.8.0.
- Remains additive within the 0.1.x API and supports Rust 1.85.0+. Runtime behavior and
  cross-format mapping remain outside QuadletLens.
