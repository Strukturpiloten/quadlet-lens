# QuadletLens 0.1.13

- Adds positive and negative boundary tests for source locations, capability catalogues, and
  document-set resolution.
- Adds a pinned coverage ratchet and explicit patch-level API checks to CI and release validation.
- Adds shared editor tasks and a one-command deterministic local format, lint, test, and
  release-readiness gate; generator and download lanes remain opt-in.
- Isolates local API checks from a container's potentially read-only Cargo installation cache.
- Preserves the documented 0.1.x API, finite Podman evidence boundary, and Rust 1.85.0+ support.
