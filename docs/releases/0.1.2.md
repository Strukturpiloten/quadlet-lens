# QuadletLens 0.1.2

QuadletLens 0.1.2 adds native container and pod host mappings for BoxFerry and other generators.
The change remains loss-aware and version-evidenced instead of treating every host value as an IP
address.

## Added

- `ContainerKey::AddHost` and `PodKey::AddHost` for parsing, inspection, programmatic construction,
  and deterministic rendering.
- Repeatable-entry behavior for both native keys.
- Capability IDs `quadlet.container.add-host` and `quadlet.pod.add-host`, with native evidence from
  Podman 5.4.0 through current 6.0.2.
- Typed and generated fixtures for `host.docker.internal:host-gateway`, arbitrary IPv4 mappings,
  pod mappings, and repeated entries including bracketed IPv6.
- Full real-generator confirmation that all 20 Podman patch releases in the supported evidence
  window emit the expected `--add-host` arguments.

## Compatibility

The public changes are additive within the documented QuadletLens 0.1.x API. Existing callers do
not need to change. Rust 1.85.0 and Podman 5.4.0 remain the minimum supported versions; the latter
is a support floor, not a maximum.

The builder and parser preserve exact one-line `AddHost` values. They do not resolve hostnames,
replace runtime tokens, or assume that an automatically synthesized Podman hostname makes an
explicit mapping redundant.
