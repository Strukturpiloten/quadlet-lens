# QuadletLens 0.1.5

QuadletLens 0.1.5 adds the native execution-identity and container-context primitives needed by
conversion tools while keeping runtime lookup and cross-format policy outside the library.

## Added

- `ContainerKey::User` and `ContainerKey::Group` for the primary container identity.
- `ContainerKey::UserNS` for Podman user-namespace selection.
- Repeatable `ContainerKey::GroupAdd` for supplementary groups.
- `ContainerKey::WorkingDir` and `ContainerKey::ReadOnly` for container execution context.
- Six data-driven capability records spanning Podman 5.4.0 through the finite current catalogue
  ceiling, Podman 6.0.2.
- Parser, builder, renderer, singleton/repetition, catalogue, and public-consumer tests.
- Real-generator fixtures accepted by all 20 recorded Podman patch releases from 5.4.0 through
  6.0.2.

## Compatibility

The public changes are additive within the documented QuadletLens 0.1.x API. Existing callers do
not need to change. Rust 1.85.0 and Podman 5.4.0 remain the minimum supported versions; Podman 5.4
is not a maximum.

## Semantic boundary

Values remain exact authored native text. QuadletLens does not resolve host users or groups,
inspect a container image's filesystem, or determine runtime namespace state. The generator
evidence proves the corresponding Podman command fragments; it does not claim rootless/rootful
runtime success for every identity combination.
