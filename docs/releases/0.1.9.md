# QuadletLens 0.1.9

QuadletLens 0.1.9 promotes explicit Podman container names from loss-aware syntax into the typed,
version-evidenced generation boundary.

## Added

- `ContainerKey::ContainerName` for source-aware parsing and typed construction.
- `quadlet.container.container-name` capability evidence from Podman 5.4.0 through 6.0.2.
- Real-generator protection for the exact `--name` argument across every supported Podman patch.

## Semantics

`ContainerName=` controls the Podman runtime container name. It remains distinct from the Quadlet
file basename, the generated systemd service name, and BoxFerry's neutral service identifier.
QuadletLens retains the exact one-line value and rejects duplicate builder assignments, but it
does not inspect existing containers or infer whether a runtime name will collide on the target
host.

The public enum variant is appended after every published `ContainerKey` discriminant. The change
is additive within the documented 0.1.x policy. Rust 1.85.0 and Podman 5.4.0 remain the minimum
supported versions; the reviewed capability ceiling remains Podman 6.0.2.
